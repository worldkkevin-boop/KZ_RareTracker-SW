# Requirements — KZ Addons Suite

## v1 Requirements

### KZ Guide

- [ ] **GUIDE-01**: Organizar e completar conteúdo dos guias de leveling (Alliance/Horde) — steps faltantes, ordem incorreta
- [ ] **GUIDE-02**: Organizar e completar conteúdo dos guias de profissões — steps faltantes
- [ ] **GUIDE-03**: Corrigir PartySync — atualmente não sincroniza nenhum dado entre membros do grupo
- [ ] **GUIDE-04**: Corrigir bugs de UI — performance lenta, elementos visuais quebrados
- [ ] **GUIDE-05**: Corrigir bugs de navegação — seta, waypoints e caminho no minimapa (após organização de conteúdo)

### KZ RareTracker

- [ ] **RARE-01**: Completar database de raros do SandWorlds — cadastrar todos os raros que faltam
- [ ] **RARE-02**: Corrigir posicionamento do ícone no minimapa — aparece errado (posição ou visual)
- [ ] **RARE-03**: Corrigir sistema de alertas/sons — falha ao notificar spawn de raro

### KZ Translator

- [ ] **TRAN-01**: Corrigir frames fora de posição no menu do addon

### KZ ItemEP

- [ ] **EP-01**: Corrigir frames fora de posição no menu de configurações

## v2 Requirements (Deferred)

- Novos addons do zero — após estabilização dos 4 existentes
- Expandir dicionário do KZ Translator — aumentar cobertura de termos
- Novas specs no KZ ItemEP — cobrir mais combinações de classe/spec
- Integração entre addons (ex: RareTracker avisa no Guide)

## Out of Scope

- Suporte a versões do WoW além de 1.12.1 — servidor-específico
- Port para outros servidores private — foco em SandWorlds
- UI redesign completo — melhorias pontuais apenas
