# RareTracker-SW

Addon para **WoW 1.12.1 (Vanilla)** que rastreia monstros raros, exibe no mapa e sincroniza os timers entre jogadores em tempo real.

Desenvolvido para o servidor **SandWorlds** (interface 11200 / build 5875).

---

## Funcionalidades

- **Mapa e Minimapa** — icones dos raros no mapa principal e minimapa com tooltips de loot e status
- **Alertas** — notificacao visual e sonora quando um raro aparece perto de voce
- **Sincronizacao** — compartilha timers de morte entre jogadores com o addon instalado via canal oculto (sem spam no chat)
- **Busca** — localize qualquer raro em qualquer zona pelo menu de busca
- **Loot** — banco de dados de drops dos raros do SandWorlds

---

## Instalacao via GitAddonsManager (Recomendado)

Baixe o **GitAddonsManager** em:
> https://woblight.gitlab.io/overview/gitaddonsmanager/

Configure a pasta do WoW e clique em **+**, colando a URL:
```
https://github.com/worldkkevin-boop/RareTracker-SW.git
```

Para atualizar: clique no botao de atualizar ao lado do addon e use `/reload` no jogo.

---

## Instalacao Manual

1. Baixe o ZIP: **Code > Download ZIP**
2. Extraia a pasta `RareTracker-SW` para:
```
WoW\Interface\AddOns\
```
3. Ative o addon na tela de selecao de personagem

---

## Comandos

```
/rt          — abre o menu principal
/rt sound    — ativa/desativa alertas sonoros
/rt dead     — mostra/oculta raros mortos no mapa
/rt search   — busca um raro por nome
```
